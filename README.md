# Smart City Hospital – Premium Healthcare Website Prompt

Create a world-class, premium, modern, highly responsive healthcare website for **Smart City Hospital – Neuro, Trauma & Women Care** using **React.js (JSX only), Tailwind CSS, Bootstrap 5, Framer Motion, Lucide React Icons, React Router, Swiper.js, and modern UI/UX principles**.

The website should feel comparable to top healthcare brands like Apollo Hospitals, Fortis, Max Healthcare, and Medanta while maintaining a unique identity inspired by the Smart City Hospital logo.
